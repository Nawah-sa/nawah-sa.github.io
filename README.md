# موقع نواة

موقع مبادرة «نواة» التقنية التطوعية في القطيف: https://nawah-sa.github.io

## محتوى المجلد

| الملف | وش فيه |
| --- | --- |
| `index.html` | الصفحة الرئيسية: الواجهة، البرامج، «من نواة إلى نخلة»، مين ورا نواة، للأهالي، التسجيل، الأسئلة |
| `privacy.html` | سياسة الخصوصية |
| `js/config.js` | **الإعدادات اللي تعدّلها أنت**: رابط الجدول، اسمك، صورتك، الإيميل، الحسابات |
| `js/main.js` | المدار في الواجهة، وتعبئة الإعدادات |
| `js/palm.js` | النخلة اللي تكبر مع التمرير (GSAP + ScrollTrigger، و Lenis على الكمبيوتر) |
| `js/form.js` | نموذج التسجيل |
| `css/style.css` | الألوان والتنسيق (ألوان «ليل النخيل» من دليل الهوية) |
| `assets/` | الشعار، والأيقونة، وصورة المعاينة `og.png` |
| `apps-script/Code.gs` | الكود اللي يحفظ التسجيلات في Google Sheets |

## تعديل الإعدادات

افتح `js/config.js` وعبّي الخانات. أي خانة تتركها فاضية، الجزء المرتبط فيها ما يطلع في الموقع:

- `sheetUrl`: رابط حفظ التسجيلات (الخطوات تحت). **زر التسجيل يبقى مقفل لين تحط هذا الرابط.**
- `founderName`: اسمك.
- `founderPhoto`: صورتك. حطها في `assets/` واكتب مسارها، مثل `assets/founder.jpg`.
- `email`: إيميل التواصل.
- `instagram` و `x`: روابط الحسابات كاملة.

## ربط التسجيل بالجدول (Google Sheets)

1. سوّ جدول جديد في Google Sheets باسم «تسجيلات نواة».
2. من القائمة: **Extensions ← Apps Script**.
3. امسح الكود الموجود، والصق محتوى `apps-script/Code.gs` كامل، واحفظ.
4. اضغط **Deploy ← New deployment**.
5. من الترس جنب «Select type» اختر **Web app**، واضبط:
   - **Execute as:** Me
   - **Who has access:** Anyone
6. اضغط **Deploy**، ووافق على الصلاحيات بحسابك.
7. انسخ رابط **Web app URL** (ينتهي بـ `/exec`)، والصقه في `sheetUrl` داخل `js/config.js`.

بعدها كل تسجيل ينضاف سطر في ورقة «التسجيلات» داخل الجدول. والجدول ما يشوفه إلا أنت ومن تشاركه معه.

## النشر (GitHub Pages)

من المستودع على GitHub: **Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save**.
بعد دقيقة أو دقيقتين يصير الموقع شغّال على https://nawah-sa.github.io. وأي تعديل ترفعه بعدها يتحدّث تلقائياً.

## ملاحظات

- الخط في الموقع IBM Plex Sans Arabic، لأن رخصة خط ثمانية ما تسمح بتضمينه في موقع.
- مكتبات GSAP و Lenis تحمّل من الإنترنت (cdnjs و unpkg). وإذا ما حمّلت، النخلة تطلع كاملة بدون حركة.
